# Maison Nyuy - fashion boutique demo
Portfolio demonstration by Vernyuy Services.

Open index.html in a browser (internet needed for GSAP and Google Fonts).

- index.html: all pages live here as views, switched by the URL hash:
  (home), #products (shop), #collections, #about, #faq, #contact-us, #admin
- css/style.css: all styles
- js/main.js: products, bag (localStorage), quick view, filters, admin demo, GSAP animations

Notes
- Prices are set directly in XAF in js/main.js (the NEW table).
- Photos: see IMAGES.md for the exact file names. Drop .jpg files into assets/images/ (matching paths) and they appear automatically; no code changes needed.
- Contact: +237 652 311 022, vernyuykahnyuy@gmail.com, WhatsApp wa.link set in js/main.js.
- The admin tab is a visual demo only: no backend, nothing is saved.
